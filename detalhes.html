O NEXUS PLAY vende jogos de verdade?
Não. Este site é um projeto acadêmico. As páginas dos jogos levam às lojas oficiais.
As imagens dos jogos são oficiais?
Sim, são imagens promocionais exibidas por meio do serviço de imagens da Steam. Se estiver offline, aparecem ilustrações de reserva.

Não. O cadastro é uma demonstração para exercitar formulários HTML5, sem envio de dados.
